# 🚀 RouteNova – Intelligent Route Optimization System

RouteNova is a web-based route planning system that computes the most efficient path between locations using graph algorithms and real-world routing data. It combines Dijkstra’s algorithm with API integration to provide optimized routes, navigation directions, and map visualization.

---

## 📌 Features

- 🔹 Shortest path calculation using Dijkstra’s Algorithm  
- 🔹 Traffic-aware routing (dynamic weight simulation)  
- 🔹 Real-world distance & directions via OpenRouteService API  
- 🔹 Interactive map visualization using Folium  
- 🔹 User authentication system (Login/Logout)  
- 🔹 Clean and responsive UI  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, Bootstrap  
- **Backend:** Python (Flask)  
- **Database:** SQLite  
- **API:** OpenRouteService  
- **Visualization:** Folium
